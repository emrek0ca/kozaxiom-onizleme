# kozaxiom.com — geçici önizleme

kozaxiom.com için hazırlanan yeni tek sayfalık sitenin önizlemesi.
Yayına Hostinger'dan alınacak; bu depo sadece bakmak için.

- Arama motorlarına kapalı (`noindex` + `robots.txt`).
- Sadece statik dosyalar var. Form işlemcisi (`send.php`) ve ayar dosyası
  bu depoda **yok** — o yüzden buradaki formu gönderince hata mesajı çıkar.
  Beklenen davranış budur.
